DataVerse Consulting

AI-assisted work for a 40-person consultancy.

Client DataVerse Consulting Sole Co., Ltd, Vientiane, Lao PDR
Role Consultant
Since Aug 2026

On-demand consulting for a ~40-person monitoring-and-evaluation consultancy in Vientiane. I designed two work lines: AI-assisted drafting of evaluation reports from survey data, and AI-assisted programming of the client’s internal systems.

What changed

Adoption, version control and code review.

  • A live AI-build test with the client’s database team led the client to adopt AI-assisted development and sign an on-demand consulting contract (Aug 2026).
  • About fifteen people moved to AI-assisted work: ten engineers in two teams and five consultants.
  • I introduced version control and a written code-review gate. Within days the team worked in a private GitHub repository with 19 requirement issues in dependency waves, a project board and pull requests.

How the work runs

A local lead, and a second technical check.

A local lead owns daily implementation. I review when a work plan, implementation, test, code weakness or security question needs a second technical check.
